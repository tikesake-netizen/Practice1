# TSIS 2 — Paint Application

## Description

This project is a simple Paint application created with Python and Pygame.

The application allows users to draw, create geometric shapes, fill areas with color, add text, and save drawings as PNG images.

## Features

- Pencil — freehand drawing
- Line — straight lines with preview
- Rectangle — draw rectangles
- Circle — draw circles
- Square — draw squares
- Triangle — draw triangles
- Diamond — draw diamonds
- Eraser — erase parts of the drawing
- Fill — flood fill enclosed areas
- Text — add text to the canvas
- Brush sizes — 2, 5, and 10 pixels
- Color selection — black, red, green, blue, and yellow
- Save — save drawings as PNG files using Ctrl + S

## Technologies

- Python
- Pygame

\# Practice 5 - Python RegEx and Receipt Parser



\## Description



This practice demonstrates the use of Python Regular Expressions (RegEx) and parsing information from a receipt.



\## RegEx Functions



The following functions were demonstrated:



\- re.search()

\- re.findall()

\- re.split()

\- re.sub()



\## RegEx Metacharacters



The following metacharacters were demonstrated:



\- .

\- ^

\- $

\- \*

\- +

\- ?

\- \[]

\- {}

\- |

\- ()



\## Special Sequences



The following special sequences were demonstrated:



\- \\d

\- \\D

\- \\s

\- \\S

\- \\w

\- \\W

\- \\b



\## Receipt Parser



The receipt parser reads data from raw.txt and extracts:



\- Product names

\- Quantity

\- Prices

\- Seller information

\- Date

\- Time

\- Total amount

\- Fiscal attribute

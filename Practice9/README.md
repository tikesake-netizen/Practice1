# Practice 9 — Pygame Games

## 1. Mickey's Clock
An analog clock made with Pygame.
- Displays a clock image.
- Shows hour, minute and second hands.
- Hands rotate according to the current time.

## 2. Music Player
A music player with keyboard controls.
- SPACE — Play / Pause
- S — Stop
- LEFT — Previous song
- RIGHT — Next song
- UP — Increase volume
- DOWN — Decrease volume

## 3. Moving Ball
A simple animation using Pygame.
- A ball moves around the screen.
- The ball bounces off window boundaries.
- Collision with screen edges changes its direction.

## Requirements
- Python 3
- Pygame 2.6.1

## Installation

```bash
pip install pygame
```

## How to Run

Run each project separately:

```bash
cd mickey_clock
python main.py
```

```bash
cd music_player
python main.py
```

```bash
cd moving_ball
python main.py
```
